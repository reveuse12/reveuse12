## Featured projects

### RAG Chat Application — Evaluated AI Document Q&A

A production RAG system with a measured retrieval pipeline. The RAGAS evaluation harness tracks **faithfulness, answer relevancy, and context precision** to tune chunking and retrieval quality. Hybrid vector and BM25 retrieval runs over pgvector with IVFFlat indexing, while every answer includes source attribution and token streaming.

**Stack:** Next.js, TypeScript, LangChain LCEL, pgvector, Google Gemini, FastAPI, PostgreSQL, Vercel AI SDK.

### [EmailEssentials](https://email-summerizer.vercel.app) — AI Email Summary SaaS

A live micro-SaaS that delivers AI email summaries via SMS. It supports Gmail and Outlook OAuth 2.0, encrypted refresh-token storage, Stripe subscription billing with signature-verified idempotent webhooks, and an asynchronous retryable job queue.

**Stack:** Next.js, OpenAI API, Stripe, Twilio, Prisma ORM, PostgreSQL, OAuth 2.0.

### [TMT Admin Panel](https://tmt-adminpanel.vercel.app) — E-commerce Operations

An operations dashboard managing **3,000+ SKUs** and **200+ purchase orders**. It uses PostgreSQL Row-Level Security across 15+ tables, idempotent Shopify synchronization with rate-limit backoff, and a zero-downtime migration from Supabase Cloud to a self-hosted VM.

**Stack:** React, TypeScript, Supabase, PostgreSQL, Shopify API, Tailwind CSS.

### Capabara — Multi-tenant Organization Platform

A multi-tenant SaaS with hierarchical organization structures and granular RBAC. Django SSO, Stripe payments, and automated Xero invoicing are backed by database-level tenant scoping so isolation cannot be bypassed by application-layer bugs.

**Stack:** Next.js, TypeScript, Django, PostgreSQL, Stripe, Xero API, AWS.
